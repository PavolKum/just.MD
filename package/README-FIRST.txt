just.MD - a markdown reader and editor that opens .md files with a double-click.

To install:
1. Copy this folder anywhere on your PC (for example your Desktop).
2. Open a Claude Code session in this folder.
3. Say: "please install this on my machine".

Claude follows INSTALL-FOR-CLAUDE.md. It takes about 2 minutes; you click "Install" once in your browser.

Needs: Windows + Microsoft Edge or Google Chrome. No admin rights, no Python; the app itself needs no internet.
Your files never leave your PC.
